# ゾロ目が出る確率

120面体サイコロ1回あたりでゾロ目が出る確率を求める。

## 結論

1回の出目がゾロ目になる確率 `P` は次のとおり。

```
P ≈ 8.3 %
```

## 前提条件

- サイコロは120面体で、出目 `v` は `1 ~ 120` の一様分布に従う
- **ゾロ目**は2桁以上で全桁が同一数字の出目とする（1桁の `1 ~ 9` はゾロ目としない）

## 計算過程

`1 ~ 120` に含まれるゾロ目を数え上げる。

2桁のゾロ目は次の9個。

```
11, 22, 33, 44, 55, 66, 77, 88, 99
```

3桁のゾロ目は `111` の1個だけで、次の `222` は120を超えるため含まれない。よってゾロ目は合計10個であり、確率は次のようになる。

```
P = 10 / 120
  = 1 / 12
  ≈ 8.33 %
```
